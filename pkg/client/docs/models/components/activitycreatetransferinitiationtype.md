# ActivityCreateTransferInitiationType

Type of transfer initiation:
- TRANSFER: Internal to internal account transfer
- PAYOUT: Internal to external account payout



## Values

| Name                                           | Value                                          |
| ---------------------------------------------- | ---------------------------------------------- |
| `ActivityCreateTransferInitiationTypeTransfer` | TRANSFER                                       |
| `ActivityCreateTransferInitiationTypePayout`   | PAYOUT                                         |
